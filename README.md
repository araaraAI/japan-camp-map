# キャンプ・車中泊マップ

全国のキャンプ場・RVパーク・道の駅を、1枚の地図で探せるページです。

**地図を開く → https://araaraai.github.io/japan-camp-map/**

## 載っているもの

- **キャンプ場** 約5,700か所、**RVパーク等** 約180か所（OpenStreetMap）
- **道の駅** 約1,100駅（国土交通省の登録一覧。位置は OpenStreetMap と照らし合わせています）
- 料金・予約・電源・トイレ・シャワー・ペット・営業期間を、わかる範囲で表示します。
  わからない項目は「不明」と出ます。

## 「公式サイトで確認」の印について

次の施設は、一つずつ施設の公式サイトや自治体・観光協会のページを読み、
書かれていたことだけを記録しています。地図では金色の縁取りが付きます。
予約サイトやまとめサイトの情報は使っていません。

- 関西（福井を含む）：キャンプ場・RVパーク・道の駅
- 西日本（三重・岐阜・愛知、中国・四国・九州・沖縄）：公式サイトの分かっているキャンプ場・RVパークと、道の駅

ほかの施設は、OpenStreetMap などの公開データに入っている値だけを表示しています。
料金や設備の欄が空いていることが多いのはこのためです。
たとえるなら、確認済みの施設は「お店に電話して聞いたメモ」、ほかは「地図アプリの登録情報」くらいの違いがあります。

## 運営終了・休止の施設

公式ページで運営終了・休止・休園中・予約受付停止と案内されている施設は、
地図から消さずに灰色の点で残し、詳細に案内の文面を載せています。

## ご利用にあたって

- 道の駅は休憩施設で、宿泊を目的とした利用は公式には認められていません。
- 料金や営業期間は変わることがあります。出かける前に、施設の公式情報を一度見ておくと安心かもしれません。
- 各施設の出典は、地図の詳細欄に載せています。
